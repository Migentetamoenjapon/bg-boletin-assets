# Imágenes del Informe de Apertura

Las imágenes que el boletín diario de BG Valores necesita servir por URL, porque un correo no
puede llevarlas adentro: Outlook y Hotmail descartan las imágenes incrustadas.

Acá **no hay datos de clientes ni información interna**: solo el logo y gráficos de mercado
construidos con cifras públicas (índices, curva del Tesoro, rendimiento sectorial).

    logo/bg-blanco.png             el logo sobre fondo oscuro, para el cabezal
    graficos/<AAAA-MM-DD>/*.png    el gráfico de cada edición

El código que los produce vive en el repositorio privado del proyecto.
